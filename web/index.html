What do these words mean?

QKD means quantum key distribution: a way to make matching secret keys.

BB84 is a method for creating and comparing key bits.

Cascade corrects disagreements between the two key strings.

Error rate (QBER) is the share of checked bits that disagree. A higher rate can come from noise or observation.

Key pool is the store of unused secret keys at a node.

Trusted relay is a middle computer that helps pass a key along and can see it, so it must be trusted.

One-time key is a key used for one message and then removed from use.
